# NYSC Medical Relocation System - Simple User Story

## What this system is

This system helps NYSC process medical relocation requests in a way that is:

- Harder to fake
- Faster to process
- Fair to genuine applicants
- Fully traceable by NYSC headquarters

Instead of paper reports, everything is done through a secure digital platform controlled by NYSC and approved hospitals.

## Who uses the system

- Corpers (NYSC participants requesting relocation)
- Approved hospitals (government and selected private hospitals)
- NYSC administrators in Abuja
- State coordinators (camp officials)

## How it works

### 1. Call-up is issued

Once a corper is mobilized, the medical relocation system becomes active for that person.

- A digital profile is created
- The corper can begin a medical evaluation request

### 2. Corper visits an approved hospital

The corper must visit an NYSC-approved hospital:

- Federal hospital
- State hospital
- Military hospital
- Selected private hospitals (limited and monitored)

Only approved hospitals can create valid medical cases.

### 3. Doctor creates a digital report

The doctor does not issue paper documents.

- Doctor logs into the system
- Doctor submits report digitally
- System generates a unique case ID and verification code

### 4. Identity is checked

The platform validates identity using NIN/BVN records.

- Exact match: proceed
- Partial mismatch: proceed with risk flag
- No match: manual review

### 5. Corper submits verification code

The corper submits the code generated for the case.

- Single-use only
- Expires after 12 hours
- Cannot be shared or reused

### 6. Fraud signals are evaluated

Before final decision, the system checks suspicious patterns, such as:

- Unusually high case volume from one hospital
- Unusual doctor throughput
- Location inconsistencies
- Repeated suspicious diagnosis patterns

### 7. Decision is generated

System returns one of four outcomes:

- Approved automatically
- Sent for review
- Rejected
- Escalated for higher authority decision

### 8. Special camp cases

State coordinators can recommend relocation in exceptional camp situations.

- Reason is mandatory
- Recommendation is logged and monitored

### 9. Final authority in Abuja

Escalated cases are reviewed centrally.

The Director-General in Abuja is final approval authority for those escalated decisions.

### 10. National visibility and audit

NYSC administrators can see:

- Every case nationwide
- Why each case was approved or rejected
- Suspicious behavior trends
- Actions taken by hospitals and doctors

## What this system achieves

- Hard to fake: only verified hospitals can issue valid medical cases
- Transparent: every step and decision is logged
- Fair: genuine cases are not blocked by rigid automation
- Controlled: high-risk decisions are centrally governed
- Efficient: low-risk cases are resolved quickly
