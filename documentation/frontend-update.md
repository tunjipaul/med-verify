

# 📌 NYSC Medical Relocation Verification System

## 🧠 Project Overview

This is a GovTech platform designed for the **National Youth Service Corps (NYSC), Nigeria** to eliminate fraud in medical-based relocation requests.

The system replaces paper-based medical submissions with a **secure, hospital-controlled digital verification infrastructure**.

It ensures:

* Only approved hospitals can issue medical reports
* Every medical case is digitally traceable
* Identity is verified using national identity systems
* Fraud is detected using behavioral and rule-based risk analysis
* Final decisions are centrally governed by NYSC HQ

---

# 🚨 Problem Being Solved

Current NYSC relocation system issues:

* Fake or forged medical reports
* Manual verification of documents
* No hospital-level authentication
* High exploitation of medical relocation pathway
* Lack of centralized audit trail

---

# 🏗️ Final System Architecture (Updated)

The system is divided into **three core layers**:

## 1. Governance Layer (NYSC HQ Only)

* Hospital accreditation
* Doctor validation (MDCN verification)
* Policy enforcement
* System oversight

## 2. Operational Layer (Core System)

* Medical case creation
* Verification code system
* Hospital + doctor workflows
* Corper case management

## 3. Intelligence Layer

* Rule-based fraud detection engine
* Risk scoring system
* Behavioral anomaly detection
* Geo and time-based validation

---

# 🧩 Key System Concepts

## Medical Case Token (MCT)

A unique system-generated identifier assigned to every medical case.

* One per corper per case
* Tracks full lifecycle of medical request

---

## Verification Code System

* Generated by system (not hospitals manually)
* One-time use only
* Bound to:

  * Corper
  * Hospital
  * Doctor
* Expires in **12 hours**
* Invalid after 3 failed attempts

---

## Identity Verification

Uses:

* Call-Up Number
* NIN
* OTP verification

Outcome types:

* Exact match → proceed
* Partial mismatch → proceed with risk flag
* No match → manual review

---

## Risk Engine (Rule-Based, Not ML)

Detects anomalies such as:

* Geo-location mismatch
* Time burst (sudden high volume issuance)
* Doctor workload anomalies
* Repeated diagnosis patterns
* Referral abuse patterns
* Hospital tier risk (private hospitals = higher baseline risk)

Outputs:

* Risk score
* Explainable breakdown

---

## Decision Engine Outputs

* AUTO_APPROVE
* REVIEW_REQUIRED
* ESCALATE (NYSC HQ)
* REJECT (only extreme violations)

All decisions must include **reason explanations**.

---

# 🏥 Hospital & Doctor Model

## Hospitals

* Do NOT self-register
* Are provisioned by NYSC HQ
* Tiered system:

  * Federal hospitals
  * State hospitals
  * Military hospitals
  * Selected accredited private hospitals

## Doctors

* Exist only under hospitals
* Must have valid MDCN ID
* Cannot operate independently
* Account created by hospital admin + validated by NYSC

* Doctor
